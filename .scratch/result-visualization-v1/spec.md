## Problem Statement

R1 已建立电脑端登录、问数 / 追问和独立经营分析闭环；现有查询表格按原始值展示，缺少统一数字格式、完整的列语义、单位与实际查询范围。经营分析已展示后端报告与确定性归因数值，但没有贡献图。用户需同时看清走势和具体数值，能够核对数据及其业务含义。

事实源：[路线图](../../docs/roadmap.md)、[产品范围](../../docs/product-scope.md)、[架构](../../docs/architecture.md)、[Web Contract](../../docs/specs/web-dialogue-v1.md)、[Query API](../../docs/specs/query-api.md)、[Online Query](../../docs/specs/online-query.md)、[领域上下文](../../CONTEXT.md)。指标与维度的权威来源为仓库 Semantic 记录；归因来源为既有 Business Analysis 确定性结果。代码只能证明当前行为，不能替代用户确认的新 Contract。

## Solution / Scope

- 首版完整覆盖问数的指标卡 / 图表 / 表格、可信结果说明，以及经营分析的两期与贡献展示。
- 同一份成功查询结果生成图表和表格，默认同时展示；可分别收起。多种图表确实适用时允许切换类型，不改变查询条件、不再次请求模型 / 数据库。
- 复用现有 React / TypeScript / Vite 与 ResultTable，新增 Apache ECharts，按需随应用打包，不使用外部 CDN。
- 兼容新增后端结果说明，将已认证的列含义、业务范围和显示格式传至网页；不让前端从列名、问题文本或数值形态猜业务含义。
- 保持当前权限、SQL Guard、100 行边界、会话生命周期、两模式隔离和真实数据链路。

### Change Profile

持续维护的跨模块 Feature，规模中等，涉及公共响应扩展、指标展示事实和新增图表依赖。风险在于误标口径 / 单位、数值精度、图表暗示错误结论，以及不可信文本和旧客户端兼容。交付包含确定性软件、API / 集成、电脑端浏览器及少量真实模型闭环证据；不新增生产部署承诺。

## User Stories

1. 查询某期间净销售额，看到带千分位的指标卡、原始明细表和可信的指标 / 单位 / 查询范围，能查看原始返回值。
2. 按月份查询指标，看到依时间排序的折线图及同一数据表格；追问改为毛利后，新一轮展示对应新指标和范围。
3. 按产品或区域查询同单位多指标，看到可对比的柱状图；不同单位分图，多个业务分组维度保留表格并说明如何通过追问改为单一分组。
4. 做两期经营分析，看到上期、本期、差额、主要产品正负贡献，选择产品查看因素贡献，并可打开报告任务证据。
5. 空值、截断、未知单位、缺失时段或图表绘制失败时，能知道展示边界并核对已有结果。

## Observable Behavior

### 1. 图表与表格

| 可信结果形态 | 默认展示 |
| --- | --- |
| 无业务分组的单行已认证指标 | 每个指标的指标卡，加同一结果表格 |
| 一个可信时间分组 | 折线图，加表格；在数据适用时可切为柱状图 |
| 一个分类分组，如产品或区域 | 柱状图，加表格；方向等局部布局由实施选择 |
| 多个业务分组维度 | 表格及单一分组建议，不自动合并 / 选取部分分组 |
| 无法可靠识别、未认证的列 | 原始值表格；可靠的其他列仍可单独展示 |

逻辑分组维度以业务语义为准，不把一个时间分组的多个物理字段误当成多个业务分组。无分组但多行 / 混合结果不能静默选第一行当指标卡。图表只使用本轮已返回值，不重新汇总、聚合、补算或自动执行查询。旧查询展示及新一轮遵守 R1 成功 / 失败提交语义，不串用上一轮元数据。

同单位多指标可在同图对比；不同单位分图，首版不引入双轴。图表类型切换和收起仅属于页面展示状态；不改变后台短期会话。退出、过期或换号清理图表、表格、提示、原始值及所有私有展示，迟到响应不写回。刷新仍按 R1 进入空白对话，不替代 R3 历史。

### 2. 可信结果说明与 API 兼容

- 后端新增可兼容忽略的结构化结果说明，已有请求与 `columns / rows / row_count / truncated / sql / conversation_id` 的语义及值保持。
- 描述每列的技术类型、业务角色（指标 / 维度 / 标识 / 未确认）、可确认的指标或维度名称、定义、单位和显示类别；与输出列的位置明确绑定，不能依赖别名相似度。
- 查询级说明包含可认证的实际时间范围、时间口径、分组与筛选条件；无时间条件应明确未限定查询时间，不把返回数据的最早 / 最晚日期冒充请求范围。无法确认的项明确标为未确认，不编造。
- 可信依据是已校验语义、权威 Semantic / Structure / Certified Physical Mapping 与实际通过 Guard 的 SQL / 输出；仅凭 LLM Candidate、列名或数据库技术类型不足以认证业务含义。
- 已登记的人民币金额、计数、毛利率展示性质可在权威来源明确维护，不由 Adapter 定义另一份业务真相；数量等未确认单位不擅自写成“件”。不更改指标公式、过滤口径或维度业务定义。
- 兼容无说明字段的旧结果 / 测试替身：保留原始表格，不猜测元数据。说明缺失、未认证或局部无效时提示并对受影响列降级；查询原本成功则仍是成功，不能仅因展示说明不可用回退会话状态。
- API 说明具体字段名称、类型与校验结构在设计审查固化，再成为实施 Ticket Contract；不得由实施任意改变上述公开行为。内部证据可审计，响应不输出内部路径、密钥或连接配置。
- 无新增查询理解 / 总结模型调用；经营分析现有报告生成调用保持，不把展示说明变成新的模型解释链路。

### 3. 数字格式与原始值

| 已认证类型 | 展示规则 |
| --- | --- |
| 人民币金额，包括归因金额 | 千分位、元、两位小数；不自动换万元 |
| 订单数 / 明细行数等计数 | 千分位，无小数；不把有小数的未知数量强制转整数 |
| 毛利率 | 原始比率乘100作为展示百分比，保留两位小数，如0.123456显示12.35% |
| 标识、编号、日期、未确认语义 | 保留其含义及原始展示，不猜为金额 / 比率，不给编号加千分位 |
| 数值NULL | “无数据”，与零和空字符串区分；空字符串仍按R1区别展示 |

表格、指标卡与图表提示的数字格式一致。格式化只影响显示，保留原始返回值，并提供可由鼠标 / 键盘操作的查看方式。不把已格式化含逗号或单位的文字当图表数据。图形坐标允许有限绘图精度，但提示和原始值不因绘图转换丢失精度；无法安全绘图时降级，不画错误数值。其他已认证数值的原始精度保留，不新增未经确认的单位。

两位小数的具体确定性舍入算法及防止浮点损失的内部机制由设计说明；异常数值 / 极小非零值不能悄悄被解释成真实的零，原始值入口保持可用，必要时提示显示已舍入。

### 4. 空结果、时间与截断

- 零行成功结果显示“没有符合条件的数据”，不画空图；仍是成功轮次。
- 零值正常展示；数值NULL不替换为0。折线对NULL或缺失时段保留断点，不跨缺失时段连线，不填充值。
- 只在时间粒度与实际时间键可信时按时间先后画图；表格保留后端返回顺序。只为表达间隔提供空的图形位置，不伪造结果行。只有一个时间点可显示点，但不宣称存在趋势。
- 时间无法可靠识别或同一分组多行且含义不明时，受影响图表降级为表格提示；不自行合并或求和。
- 当前查询最多返回100行；截断时图表和表格均明确“仅展示部分数据”。只画已返回数据，不把它宣称为完整走势、完整排名或全量占比，不补写整体结论。
- 首版不改变后端默认行限制 / ORDER BY，不新增获取全量的分页接口；展示长标签 / 全部已返回分类的布局不得静默丢数据。

### 5. 经营分析与证据

- 保留既有报告标题、摘要、发现、趋势、原因、建议及证据；增加两期金额与差额展示、主要产品贡献条形图、选择单产品后的因素贡献条形图。
- 指标范围仍是既有人民币净销售额 / 毛利、两个时期、产品因素归因。价格 / 销量 / 成本因素仅在后端返回时展示，不为缺失因素造数。
- 正 / 负 / 无变化及产品新增 / 持续 / 退出等含义沿用后端确定性字段与归因 Contract；展示目标指标的增减，不从成本自身方向推断对毛利的影响，不把退出分类解释成停产事实。
- 图表沿用后端对账结果和权威数值，不在浏览器重算归因或补写报告；缺失归因不画贡献图，沿用已有可用报告及证据。
- 主要贡献列表若有省略产品，明确还有多少未展示，不把列表画成完整占比，不自行算“其他产品”填满图形。
- 查询任务证据仍可展开，标明完成 / 失败 / 跳过及现有不完整证据提示，不把任务失败数据画成完整图表。不为证据新增 SQL 暴露，保持现有分析响应的安全公开边界。
- 归因结构非法或对账未通过继续遵守既有无效报告处理，不以新绘图功能绕过R1校验。

### 6. 展示失败与安全

- 图表模块加载 / 绘制失败保留可用表格及说明，提示图表不可用，不自动重试模型，不将原成功查询当业务失败。
- SQL、报告、列名、标签、单位说明和图表提示均作为不可信内容安全展示；不执行返回HTML /脚本 /链接动作。显示规则由程序决定，不接受模型输出ECharts配置或执行代码。
- 图表提示、选择、展开与收起有可理解的文字 / 键盘入口；增减方向不只靠颜色区分，表格和文字作为可核对入口。范围继续为电脑端Chrome，不新增移动端承诺。

## Testing Decisions / Acceptance

验证需绑定最终clean代码candidate、实际base、适用范围及运行资源；文档回填可说明复用理由，不把历史成绩改称新候选成绩。当前未执行下列验收。

| 场景 | 可观察验收 |
| --- | --- |
| 单值金额 /计数 /毛利率 | 同一返回值正确格式化，单位可信，原始值可核对，标识不被格式化 |
| 时间趋势与追问 | 图 /表默认同显、时间图升序，追问后指标 /单位 /范围同步、不串上一轮说明 |
| 分类与多指标 | 同单位同图、不同单位分图、多业务维度仅表格提示；支持分类长标签及全部已返回数据 |
| 展示控制 | 收起 /展开 /适用类型切换不重查、不改会话，可键盘操作 |
| 不完整数据 | 零 /NULL /空字符串 /空行正确区分；缺失时间断点、单点无趋势暗示、截断共同提示 |
| 语义降级 | 旧响应、未知单位、错误映射、重复分组、局部说明无效时保留数据并提示；不从别名猜指标 |
| 经营分析 | 两期 /差额 /产品与因素贡献匹配后端对账；证据身份正确，省略产品和不完整任务提示保留 |
| 安全及运行失败 | 恶意标签 /提示不执行HTML或脚本，加载 /绘图失败保留表格，退出 /换号不泄露旧图 |
| API兼容 /后台边界 | 旧字段值和调用方式不变，无额外LLM调用，无权限 /Guard /会话 /Checkpoint回归 |
| 开发及打包 | 容器Vite热更新与打包后同源网页可用；依赖锁定与安全检查通过 |
