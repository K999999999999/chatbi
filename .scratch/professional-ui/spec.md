# 专业产品感的桌面 Web 界面

## 目标

改善 ChatBI 当前桌面 Web 界面的视觉质量与信息层次，让问数和经营分析体验看起来像成熟、正式的业务产品，而不是功能 Demo；日常提问、理解分析结果和浏览历史应更直观。

## 预期结果

- 登录页、主工作空间形成一致、清楚、精致的视觉语言。
- 主工作空间以自然语言对话为入口，以专业 BI 结果呈现为支撑；侧栏、标题区、输入区、历史、指标卡、图表、表格、分析报告和运行状态的层级容易辨认。
- 字体、色彩、间距、边框、交互状态和窄桌面视口下的布局协调，避免临时 Demo 的观感。
- 保留现有能力、业务文案含义、数据内容、安全提示、交互行为和电脑端支持边界；不新增业务功能或改变查询 / 分析逻辑。

## 范围与边界

- In Scope：浏览器登录 / 改密界面，以及问数工作空间中已有的模式、历史、对话、结果、图表、经营分析、操作状态和交互反馈的视觉与必要呈现结构调整。
- Out of Scope：业务行为、API、权限 / 身份、安全语义、产品支持范围、导出文件版式、手机端承诺、路线图优先级和新功能。
- 按现有桌面端 Spec 和 `min-width: 960px` 支持边界设计。

## 验收方式

- 登录与工作空间具有统一的产品视觉层级；主要操作、当前模式、运行状态、对话问题和结果内容易于快速定位。
- 问数与分析历史、指标 / 图表 / 表格及其既有状态均仍以原语义呈现，视觉变化不掩盖数据可信度、截断或未经校验等提示。
- 现有桌面视口下布局无明显重叠、横向溢出或难以辨认的控件；交互控件有清晰状态与焦点样式。
- 以源代码审查、`git diff --check`、前端构建及可用的手动浏览器预览验证。仅视觉改动不新增测试。

## 验证方式

- `npm run build`（`frontend/`）验证 TypeScript 与生产构建。
- 检查 Diff、CSS / JSX 的可读性、原有交互结构、安全显示与可访问名称 / 焦点；若环境允许，手动预览桌面主界面。
- 按仓库流程执行实现后只读 Code Review；不运行测试套件。

## 授权依据

用户于 2026-10-13 确认采用“专业 BI 工作台承载 ChatGPT 式对话”的方向，并明确主要目标为好看、直观、优秀、专业、像公司的正式产品；本 Spec 将其限定为保留功能和业务语义的桌面端视觉升级。
