## 行为与验收

- 单指标和多指标的输出聚合表达式必须按认证指标顺序匹配权威公式，不允许遗漏、替换、增加指标或改变公式。
- 指标固定过滤条件必须作为顶层 WHERE 的必需 AND 子条件存在；不得通过 OR、NOT、错误字段/操作符/值或仅在 HAVING / CASE 中出现来绕过。固定条件之外的合法用户筛选保留；单指标不继承多指标对所有 OR、HAVING 或维度表达式的专用限制。
- 使用 SQLGlot AST 解析和既有物理字段规范化；允许空白、函数大小写、表别名和无意义括号差异，不新增通用数学/布尔等价推理。
- 不符合约束时沿既有 `SQL_REJECTED` 返回，数据库不执行，不修改 SQL、不自动调用模型修复。正确单指标（含现有 HAVING / 时间表达式）、实体类和多指标查询保持适用行为。
- 在公共校验器和正式授权后的查询链路验证；经营分析使用真实 TaskSemanticAdapter / TaskExecutor 调用同一授权查询链路。
