# 最后一名管理员并发保护短 Spec

## 目标
确保并发用户角色 / 启用状态修改不能同时通过“至少保留一个 active admin”检查并提交，落实现有 RBAC 不变量。

## 行为与范围
- 所有可能移除 active admin 身份的现有管理写路径，在同一 PostgreSQL transaction 内串行执行保护检查及后续修改。
- 若前一事务已经移除另一名管理员，后续事务重新读取后必须抛出 `LastAdminError`，并回滚其修改。
- 不改变固定角色、授权语义、数据库 Schema 或管理 API 行为。
- 以固定 `admin` Role 行作为事务级 `FOR UPDATE` 串行点；先通过真实 PostgreSQL 并发测试验证权限、锁等待、提交及最终状态。

## 验收与验证
- 真实 PostgreSQL 上并发降级两名管理员时，最多一个事务成功，最终至少一名 active admin 保留。
- 原有单事务、管理入口和 RBAC 测试通过；静态质量检查通过。
