# Course Schema Baseline V1

> 仅描述 PostgreSQL public Schema 的表、字段和约束。业务规则、指标公式和查询策略不属于本文件。

表：dim_customers
- customer_id INTEGER [主键]：客户ID
- customer_name VARCHAR(100)：客户名称
- customer_type VARCHAR(50)：客户类型
- industry VARCHAR(50)：客户所属行业
- country VARCHAR(50)：国家
- region VARCHAR(50)：客户所属区域

表：dim_products
- product_id INTEGER [主键]：产品ID
- product_name VARCHAR(100)：产品名称
- product_line VARCHAR(50)：产品线
- category VARCHAR(50)：产品类别
- tech_route VARCHAR(50)：技术路线
- standard_cost DECIMAL(10,2)：标准/预算成本
- material_cost DECIMAL(10,2)：材料成本
- labor_cost DECIMAL(10,2)：人工成本

表：sales_orders
- order_id BIGINT [主键]：订单ID
- order_no VARCHAR(50) [唯一]：订单号
- customer_id INTEGER：客户ID
  外键 → dim_customers.customer_id
- product_id INTEGER：产品ID
  外键 → dim_products.product_id
- region VARCHAR(50)：销售区域
- order_date DATE：订单日期
- order_status VARCHAR(20)：订单状态
- quantity DECIMAL(10,2)：销售数量
- unit_price DECIMAL(10,2)：单位价格
- discount_amount DECIMAL(10,2)：折扣金额
- gross_amount DECIMAL(12,2)：含税总额
- net_amount DECIMAL(12,2)：不含税收入
- currency VARCHAR(10)：交易币种

表：exchange_rates
- rate_date DATE [主键]：汇率日期
- currency VARCHAR(10) [主键]：交易币种
- rate_to_cny DECIMAL(10,4)：兑人民币汇率
联合主键：rate_date + currency

表：finance_expenses
- expense_id BIGINT [主键]：费用ID
- expense_date DATE：费用日期
- department VARCHAR(50)：费用归属部门
- rd_expense DECIMAL(12,2)：研发费用
- selling_expense DECIMAL(12,2)：销售费用
- admin_expense DECIMAL(12,2)：管理费用
- finance_expense DECIMAL(12,2)：财务费用
- marketing_expense DECIMAL(12,2)：市场费用
- logistics_expense DECIMAL(12,2)：物流费用
- warranty_expense DECIMAL(12,2)：质保费用
